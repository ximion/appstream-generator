# uPlot (vendored)

This directory contains a verbatim copy of the [uPlot](https://github.com/leeoniya/uPlot)
charting library, used by the generated HTML report pages.

| | |
|---|---|
| Upstream | https://github.com/leeoniya/uPlot |
| Version | 1.6.32 |
| Git tag | `1.6.32` (commit `e995b061e9fc5476a6d862cd2fb2ebc7452ca012`) |
| License | MIT - see `LICENSE` |

## Updating

1. Pick a release tag from https://github.com/leeoniya/uPlot/tags.
2. Download that tag's tarball and replace, from it:
   * `dist/uPlot.iife.min.js` → `uPlot.iife.min.js`
   * `dist/uPlot.iife.js` → `uPlot.iife.js`
   * `src/uPlot.css` → `uPlot.css`
   * `LICENSE` → `LICENSE`
3. Update the version, tag and commit in the table above.
